## 🛸 Predictive Intelligence Added

**What:** Implemented a behavioral-based route prefetching system (`RoutePredictor`) directly into the React router lifecycle that dynamically `import()`s page chunks before the user even clicks.
**Why:** The app uses Vite code splitting (React `lazy`), meaning each of the 20+ pages requires a network round-trip on first click, introducing latency.
**Signal used:** User navigation sequences (Markov chains) recorded locally in `localStorage` (`oracle_transitions`). If a user typically navigates `/dashboard` -> `/chat` -> `/documents`, the system learns this pattern and begins prefetching `/chat` the moment they land on `/dashboard`.
**How users feel it:** After a few minutes of normal usage, navigation to their most commonly used tools will feel impossibly fast (near 0ms perceived loading time), as the bundle will already be in the browser cache.
**Accuracy:** Highly accurate for power users with established workflows (e.g., lawyers repeatedly using the Estimator and Chat). Gracefully defaults to predicting common starting points (`/dashboard`, `/chat`) for new users.
**Failure mode:** If the prediction is wrong, the browser simply caches an unused small JS chunk (~20kb) in the background. If `localStorage` is disabled or full, the system degrades silently to standard React `lazy` loading.
**Next:** Predictively pre-warming RAG LLM contexts based on the specific document the user is hovering over in the `DocumentsPage`, effectively hiding inference latency.
