This product has Drafted Documents (users generate legal notices, consumer complaints). Users do generate these documents and download them.
Therefore users obviously need a Document History / Saved Documents feature —
because it is highly likely that a user might need to refer back to a drafted document later, modify it slightly for a new recipient, or just keep a record of what they drafted.
It doesn't exist because the MVP probably focused on the generation capability itself rather than storage and lifecycle.
I'm building it because it provides continuity and utility, turning a one-off tool into a personal legal repository.
