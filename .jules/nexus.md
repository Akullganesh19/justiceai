## YYYY-MM-DD — Document History / Saved Documents
**Product understood as:** A comprehensive legal co-pilot that helps users draft documents, track cases, and analyze legal situations.
**Derivation reasoning:** The product has a document generator (DocumentsPage) that allows users to create documents like Legal Notices. Users take the action of filling out forms and generating these documents. Therefore, users obviously need a way to view their previously generated documents (Document History) — because repeatedly drafting the same notice or losing a drafted document is frustrating. It doesn't exist because the drafting tool currently just renders the document and expects the user to copy/download it immediately. I'm building it because it provides continuity and memory to the document generation workflow.
**Feature built:** Saved Documents history in DocumentsPage
**User impact:** Users can now see a history of documents they have generated, view them again, and copy/download them without having to re-fill the form.
**Next logical feature:** Ability to edit a previously generated document (re-populate the form with the old data).
