## 2024-05-24 — Predictive Route Prefetching
**Product understood as:** An AI-Powered Legal Co-pilot for Indian Citizens containing informational content and specialized tools (e.g., Document Generator, AI Chat, Case Tracker).
**Prediction invented:** Implemented Predictive Route Prefetching (Oracle) to anticipate user navigation.
**Data used:** User hover (`mouseover`) and touch (`touchstart`) actions on anchor tags (`<a>`), mapping the target URL to predefined route chunks.
**Impact:** Significantly reduced perceived latency by preemptively fetching the lazy-loaded chunk for the target route before the user even clicks, creating an instant navigation feel.
**Next opportunity:** Prefetching specific API data for certain high-value tools (e.g., pre-computing Estimator responses or fetching common legal queries based on the page context).
