## 2024-05-24 — Route Prefetching

**Product understood as:** AI-Powered Legal Co-pilot for Indian Citizens. An SPA built with React Router.
**Prediction invented:** Predictive Route Prefetching. Background fetching of React component chunks based on hover intents on links.
**Data used:** Mouseover and touchstart events on `<a>` tags.
**Impact:** Perceived load time on navigation will drop significantly as the route chunk is already downloading or downloaded before the user completes the click.
**Next opportunity:** Prefetching AI model responses based on partially typed user inputs in the Chat.
