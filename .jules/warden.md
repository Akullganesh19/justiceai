## 2026-06-20 — Centralized Logger Redaction and Console Pruning
**Data traced:** PII (Email, Phone, SSN, Credit Cards) and User Prompt Query Logs
**Exposure found:** PII and User Queries were logged in plaintext directly to standard output via scattered `console.log`, `console.warn`, and `console.error` calls across `server.js` (including full prompt string subsets and `req.body` keys).
**Fix:** Created a centralized Winston logger formatter using regex to irreversibly mask PII strings. Replaced all raw `console.*` calls with `logger.*` invocations to securely funnel log outputs through this filter. Completely removed prompt logging.
**Coverage confirmed:** Masking was successfully verified by piping a test query containing mock PII to the `/api/chat` route and checking standard output to ensure the custom formatter redacted the output and prompt content was no longer exposed. Masked circular references to prevent errors.
**Still exposed elsewhere:** The current configuration only masks logs managed by `winston` via the Express server. System errors, exceptions thrown outside the Express context, client-side React tracking/errors, database inserts (like caching or query history if any), or third-party loggers not interceptable by Winston may still leak data. PII exposure inside PDF/TXT uploaded documents themselves could still remain unredacted during extraction.
