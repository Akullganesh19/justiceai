## YYYY-MM-DD — Sync AI Chat Case Analysis with Case Tracker
**Systems connected:** AI Chat Analysis (justice_ai_history) ↔ Case Tracker (justice_ai_case_tracker_v2)
**Intelligence emerged:** The AI system generates highly structured legal timelines and strategies during a chat consultation, but this data vanishes into static chat history. Connecting it to the Case Tracker makes the timeline actionable, allowing users to track the progression of the legal case generated by the AI automatically without manual data entry.
**Data flows:** When an AI Chat consultation finishes or updates its analysis (with a timeline), a background process (or shared context hook) extracts the structured timeline and creates/updates a tracking case in `justice_ai_case_tracker_v2`.
**Coupling approach:** Event Bus / Shared Logic. The chat system does not need to know about the tracker UI. We can use a custom hook `useSyncChatToTracker` inside `ChatPage` or expose an export button in `AnalysisPanel` that fires the cross-system sync loosely. Alternatively, a global hook monitors `justice_ai_history` for changes and syncs them directly into `justice_ai_case_tracker_v2`.
**Next connection:** Errors ↔ Usage. Send React error boundaries events to user sessions to flag "high risk" users experiencing bugs.
