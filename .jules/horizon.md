## 2026-11-03 — Migrate to React Router Data API
**Risk identified:** The project uses the older component-based routing (`<BrowserRouter>`, `<Routes>`, `<Route>`) from `react-router-dom` v6. This pattern is rapidly becoming obsolete as the ecosystem and the maintainers themselves move toward the Data Router API (`createBrowserRouter`, `RouterProvider`), which is required for data loading, actions, early data fetching, and upgrading to React Router v7. If left unchanged, we will be unable to adopt these modern, performance-enhancing features and technical debt will compound.
**Migration target:** React Router Data API (`createBrowserRouter` and `RouterProvider`).
**Migrated this session:** Converted the root rendering block in `src/main.jsx` to use `createBrowserRouter` and `RouterProvider`. Extracted the global shell elements (`ScrollToTop`, `CommandPalette`, `FloatingVoiceButton`, and `<Suspense>`) into a new `src/components/layout/RootLayout.jsx` file which serves as the root element containing an `<Outlet />`. All existing pages were configured as children of this root layout.
**Remaining:** Migrate individual pages to use route loaders and actions instead of `useEffect` for data fetching/mutations where applicable.
**Next session:** Identify a page component (e.g., Dashboard or Chat) that fetches data on mount, and refactor it to use a React Router `loader` function.
